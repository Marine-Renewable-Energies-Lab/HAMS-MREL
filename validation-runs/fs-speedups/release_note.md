# Release note, field-pass speed-ups (for the second-order release)

- The field passes of `qtf_terms = full` and `qtf_b2 = control` are faster: on the OC4 WAMIT model (5022 panels, sum QTF) the run takes 2.08 h (49.8 core-h) instead of 7.25 h (174.1 core-h), 3.5 times faster, and is 2.6 times faster than Nemoh v3.0.3 on the same mesh (5.46 h). The changes are deep-water Green-function rows at finite depth from k0 h = 10, reuse of ψ in the fields passes, a threaded mode check, and the partial waves on the circle from the hull integral.
- On by default: `field_deep_kh = 10` and `qtf_fs_circle = panels`. Switch them off with `field_deep_kh = 0` (gives the earlier results to the byte, apart from `qtf_fs_circle`) and `qtf_fs_circle = samples`. The ψ reuse and the threaded check have no key and give the same bits as before. `qtf_fs_inner = source` is off by default (`stencil`) because it failed the accuracy gate; do not switch it on for results.
- Results move where the deep-water rows replace the finite-depth field above ν h = 50, where the finite-depth series is unreliable: on OC4 `QTF_Indirect.11s` changes by up to 6.6 % of the largest value below 1.55 rad/s and by more above 1.6 rad/s (35.1 % for mode 6, 62.5 % for the B2 term). The change is explained but has no exact reference, so it is not proven right; the quadratic and body part moves closer to WAMIT (maximum F_x error 13.7 to 10.0 %).
- Details: `docs/second_order_validation.md` (Field-pass speed-ups) and `docs/input_files.md` (`field_deep_kh`, `qtf_fs_circle`, `qtf_fs_inner`).
